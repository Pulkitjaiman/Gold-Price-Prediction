# 🟡 Gold Price Predictor

A real-time web application that predicts gold prices using market and macroeconomic indicators like:
- Crude Oil Price
- USD Index
- S&P 500 Index
- Consumer Price Index (CPI)
- Interest Rates

## 📦 Features
- Real-time data fetching (Yahoo Finance, FRED)
- Linear Regression Model
- Peak and Trough Detection
- Visualization of gold trends

## 🚀 How to Run

```bash
git clone https://github.com/your-repo/gold-price-predictor.git
cd gold-price-predictor
pip install -r requirements.txt
streamlit run app.py
